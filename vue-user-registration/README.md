# Vue User Registration Project

## Overview
This project is a simple Vue.js application for user registration. It provides a user-friendly interface for new users to create an account.

## Project Structure
```
vue-user-registration
├── public
│   └── index.html
├── src
│   ├── assets
│   ├── components
│   │   └── UserRegistrationForm.vue
│   ├── views
│   │   └── RegistrationPage.vue
│   ├── App.vue
│   └── main.js
├── package.json
├── vite.config.js
└── README.md
```

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd vue-user-registration
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Running the Application

To start the development server, run:
```
npm run dev
```

The application will be available at `http://localhost:3000`.

## Features

- User registration form with validation
- Responsive design
- Easy to extend and customize
